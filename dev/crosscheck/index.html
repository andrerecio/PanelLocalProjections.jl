Cross-checks

This page is crosscheck/README.md of the repository.

Scripts that compute the reference numbers the Julia tests compare against: Stata through PyStata, and R. The scripts are committed. The local toolchain and the run outputs (.venv/, crosscheck/ado/, crosscheck/out/) are not.

Setup (once per machine)

uv venv .venv --python 3.13
uv pip install --python .venv/bin/python -r crosscheck/requirements.txt
.venv/bin/python crosscheck/run_do.py crosscheck/stata/setup_stata.do --log crosscheck/out/setup_stata.log
.venv/bin/python crosscheck/ado_manifest.py --check     # installed files match the committed checksums
.venv/bin/python crosscheck/run_do.py crosscheck/stata/smoke.do
Rscript crosscheck/R/smoke.R

setup_stata.do installs every package into the project-local tree crosscheck/ado/. common.do points sysdir PLUS/PERSONAL there, so the user's own Stata setup is never touched. Versions and pins are in VERSIONS.md.

Running a cross-check

.venv/bin/python crosscheck/run_do.py crosscheck/stata/<script>.do --log crosscheck/out/<script>.log
Rscript crosscheck/R/<script>.R

Each do-file starts with do "$PLP_ROOT/crosscheck/stata/common.do". run_do.py sets PLP_ROOT to the repository root and runs the do-file from its own directory, in a fresh Stata session each time (~1–2 s). The exit code is the Stata return code.

Conventions every script follows

  • set type double (in common.do) and import delimited …, asdouble. Stata's float storage otherwise costs about 1e-7 relative error.
  • Inputs are the committed synthetic panels in test/fixtures/synthetic/, or local-only data under docs/references/ whose outputs go to test/fixtures/local/ (gitignored).
  • Outputs are written at full precision: Stata %21x or %21.0g; R format(x, digits = 17) or data.table::fwrite. Committed outputs go to test/fixtures/{stata,r}/ and are listed with their provenance in test/fixtures/README.md.
  • A re-run rewrites the committed fixture in place, so git diff --exit-code test/fixtures shows any change. Every committed fixture has reproduced byte for byte so far.
  • fixest ≥ 0.13: ssc(K.adj = , G.adj = ), explicit fixef.rm, explicit vcov =.
  • MSS LP_panel needs a base data.frame (as.data.frame() first). It is reliable only in its H = 0 mode with pre-built leads and lags.

Command ↔ Julia call map

Filled in phase by phase. Each row gives the exact panellp/vcov options that reproduce a reference command: singletons, timelags, ssc, psd, absorb, dist.

Phase 1: fixed effects

Every row is a committed test (test/test_crosscheck_p1.jl), at horizons 0–6 on both synthetic panels unless noted. The test requires each reference spec to have its exact number of rows and a Julia mapping. It compares coefficients, standard errors, observations, critical degrees of freedom, numbers of clusters or periods, and reghdfe's e(df_a) and e(df_a_initial). The formula is leads(y) ~ x + lags(x, 1) + lags(y, 1) + w plus the fixed effects listed. "drop"/"keep" is the singletons keyword. Agreement is the largest relative difference over all horizons, terms and panels.

xtlp …, tfe counts the absorbed degrees of freedom as N + T − 1, which assumes the unit and time effects form one connected component. panellp counts the components, as reghdfe does. On a sample with disconnected blocks the two differ, so the xtlp tfe mapping holds for connected samples only.

Phase 2: split-panel jackknife

Committed tests in test/test_crosscheck_p2.jl, at horizons 0–3 on both synthetic panels unless noted, with the same checks as Phase 1: row counts, every spec mapped, coefficients, standard errors, observations, critical degrees of freedom (not under ase) and numbers of clusters. The estimator is SplitPanelJackknife(); the formula is that of Phase 1, or leads(y) ~ x + w ("no lags": units with two or three rows enter, with single-row halves).

Phase 6c: first-stage diagnostics

firststage(r; vcov) against ivreghdfe's e(widstat) (Kleibergen–Paap rk Wald F) and weakivtest's r(F_eff) (Montiel Olea–Pflueger effective F). These are the just-identified rows of p6_lpiv.csv (one and three endogenous regressors) and the over-identified ones of p6c_firststage.csv (s & mp + sv & mp). Their small-sample factor counts the first stage's regressors: the exogenous ones plus the excluded instruments, which is firststage's own count. With a fixed effect nested in the cluster, ivreghdfe's df′ is max(df_a − its levels, 1).
