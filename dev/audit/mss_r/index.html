Audit: Mei–Sheng–Shi replication code

Source. metricshilab/panel-lp-replication at commit 882b046, MIT licence:

  • applications/LP_panel_all.r (the function behind every empirical result);
  • simulations/, simulations_appendix/;
  • applications/replication.ipynb.

Line numbers refer to that commit. The findings come from reading the code. Those marked verified were checked by running it on the synthetic panels or on the authors' data.

What the published numbers depend on

The notebook calls LP_panel with H = 0 and outcome, lead and lag columns pre-built in Stata. Every published empirical number comes from that mode. In it, the function is reproduced exactly by panellp (verified, about 1e-12 on all four applications). Four choices of the code move the published numbers:

choiceeffect (verified)panellp
One-sweep two-way demeaning (te = T, lines 215–301)exact only on a balanced sample; moves the Romer–Romer unemployment SPJ path by up to 6% and its standard errors by 12–18% (see the replication page)OneSweep() reproduces it; the default AlternatingProjections() is exact
The split $\lceil n_i/2\rceil$, where the paper's $\{t \le T_h/2\}$ gives $\lfloor n_i/2\rfloor$with odd counts: Romer–Romer GDP peak (Table 1) −6.285 instead of −6.606 under the paper's split; Cerra–Saxena $h = 10$: −7.893 vs −7.698; Baron–Verner–Xiong bank crash, $h = 4$: −4.213 vs −4.297split = :ceil (default, as the code and xtlp) or :floor (the paper)
The eigenvalue repair (eigens = T) of the Baron–Verner–Xiong two-way variance, absent from the paper's formula (online appendix B.2.1)fires at every horizon; standard errors up to 13% larger than unrepairedpsd = :raw
File-level small-sample factors (robust = T, lines 335 and 368): $N$ and $T_0$ count the units and periods in the input file, not in the estimation sample; the two-way factor subtracts $N$changes the Baron–Verner–Xiong standard errors onlyssc = :mss

Discrepancies with the paper

  • Odd split. The code puts $\lceil n_i/2\rceil$ rows in the first half; the paper's $\{t \le T_h/2\}$ puts $\lfloor n_i/2\rfloor$. SplitPanelJackknife(split = :ceil) follows the code (and xtlp); :floor follows the paper. The effect on the published numbers is in the table above.
  • Small-sample factors. The paper's variances have none. The main-text simulation code always applies $N/(N-1)\,(n-1)/(n-K)$; the appendix code applies none.
  • Appendix Driscoll–Kraay. The December 2025 fix was applied to the FE branch only. The SPJ branch (simulations_appendix/scripts/02-03-error-calculation.R, lines 158 and
    1. still divides the long-run variance by $T_h$ and adds the unit-clustered meat,
    which affects Figures C4–C6. panellp implements appendix B.2.2 as written.
  • Analytical bias correction (DB). The simulation code estimates $\rho$ by pooled OLS, drops the third term of $f_{T,h}$, and uses the FE standard error. It is not part of this package.

Not used

The EPS figures were not used as targets. The plotted paths come from the same R code that panellp reproduces to about 1e-12 on the same data.
